# nexus-fixfirst-demos

Temporary fix-first demo host for Nexus Design Agency outreach.

Each page under `d/<code>.html` is an inert, `noindex` before/after mockup generated
from a live audit of one prospect's site. No buttons dial or submit. This repo exists
only to make the short demo links reachable while the primary host
(`nexusdesign.agency`) is offline.

Short link shape: `https://sgscrap.github.io/nexus-fixfirst-demos/d/<code>.html`
